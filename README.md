# Customer Intent Classification Using DistilBERT

## Claim Statement

I claim that fine-tuned DistilBERT achieves a macro F1-score at least 5 percentage points higher than a TF-IDF + logistic regression baseline for customer intent classification, and we will test this claim on the Bitext Customer Support Dataset.

## Project Overview

This project explores how deep learning can improve customer service through natural language processing (NLP). The goal is to develop a classification system that identifies both the broad category and the specific intent behind a customer's message.

## Project Track

Model Review and Demo

## Model Architecture

The proposed model uses a shared DistilBERT encoder with two classification heads:

- Category Classification Head
- Intent Classification Head

Both heads will use the contextual representations generated by DistilBERT to make predictions.

## Models and Baselines

- DistilBERT: Fine-tuned dual-head classification model
- TF-IDF + Logistic Regression: Traditional machine learning baseline
- OpenJev: additional model comparison

## Dataset

Bitext Customer Support Dataset from Hugging Face.

The dataset provides customer service messages labeled by category and intent.

## Evaluation Metrics

- Macro F1-score (primary metric for intent classification)
- Accuracy
- Precision
- Recall
- Category and intent classification performance
- Confusion matrices

## Perturbation Study

Evaluate how model performance changes when customer messages are paraphrased while preserving their original intent.
